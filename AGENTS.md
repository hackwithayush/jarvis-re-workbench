# Workspace Rules

## Browser Configuration
- **Localhost & Web Previews**: Whenever launching or opening `localhost` (e.g., `http://127.0.0.1:8000` or any local server URL), always use **Firefox** as the browser.
- Windows launch command: `cmd /c "start firefox <url>"` or `& "$env:LOCALAPPDATA\Microsoft\WindowsApps\firefox.exe" <url>`.
